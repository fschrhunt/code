# Workframe 1.5.1

Workframe 1.5.1 adds the native macOS menubar companion and packages it with
the matching Workframe CLI as a Homebrew cask. The app can check Homebrew for
an available update and run the matching cask upgrade.

## Homebrew cask

The cask installs `Workframe.app` and exposes its bundled CLI as `workframe`
and `wf`, so human and terminal interfaces use the same release. Existing
Workframe stores remain in the user's configured root and are not changed by
switching from the CLI formula to the cask.

## Security notice

The initial cask release is intentionally unsigned and not notarized because
the project does not have an Apple Developer Program membership. macOS will
warn before it opens the app. The cask and release notes identify this clearly;
only install it if you trust the project and release artifact.

## Validation

The release is covered by ShellCheck and the hermetic Bats suite. The unsigned
release workflow uses a macOS GitHub runner to build the app and attaches both
the ZIP archive and its checksum-pinned cask definition to the GitHub release.
