# Workframe 1.5.2

Workframe 1.5.2 fixes the packaging of the unsigned macOS menubar app.

## Unsigned app bundle integrity

The release build now ad-hoc signs and verifies the completed app bundle after
embedding the Workframe CLI and app resources. This gives macOS a structurally
valid bundle while keeping the release unsigned and unnotarized.

macOS will still require a user to approve the app on first launch because the
project does not have an Apple Developer Program membership. Once approved,
the menubar app and its bundled `workframe` and `wf` commands use the same
release.
