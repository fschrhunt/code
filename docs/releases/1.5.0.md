# Workframe 1.5.0

Workframe 1.5.0 establishes a single product identity across the command,
environment, filesystem, tests, help, documentation, CI, and workspace
configuration.

## Highlights

- `workframe` is the sole CLI entry point.
- Product controls use the `WORKFRAME_*` namespace.
- Local data defaults to `~/workframe`.
- Shared execution uses `$BOX_ROOT/system/bin/workframe`.
- The optional mount helper is `contrib/mount-workframe.sh`.
- Help and version output report `workframe 1.5.0`.
- The documentation is reorganized as a guided public library.

## Fresh-start release

This release has no compatibility command, variable, path alias, or automatic
store import. Initialize a new profile and clone the repositories you want to
manage:

```bash
workframe init
workframe agents add codex
workframe clone owner/repo
```

Existing stores and deployed binaries are not modified or deleted.

## Validation

The release is covered by ShellCheck, hermetic frontend/backend Bats tests,
installer and mount-helper checks, exact help output, and documentation/brand
audits.

See [Getting started](../getting-started.md) and
[Operations](../operations.md).
