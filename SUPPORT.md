# Support

Choose the channel that matches what you need:

- **Usage and setup questions:** start a
  [GitHub Discussion](https://github.com/fschrhunt/workframe/discussions).
- **Reproducible bugs:** use the
  [bug report form](https://github.com/fschrhunt/workframe/issues/new?template=bug_report.yml).
- **Feature ideas:** use the
  [feature request form](https://github.com/fschrhunt/workframe/issues/new?template=feature_request.yml).
- **Security vulnerabilities:** report them
  [privately](https://github.com/fschrhunt/workframe/security/advisories/new)
  as described in [SECURITY.md](SECURITY.md).

Workframe is maintained on a best-effort basis. Please include the output of
`workframe version`, your operating system, and a minimal sanitized reproduction.
Never post credentials or private infrastructure details.
