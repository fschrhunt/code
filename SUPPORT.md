# Support

- [GitHub Discussions](https://github.com/fschrhunt/code/discussions) for setup and usage questions.
- [Bug reports](https://github.com/fschrhunt/code/issues/new?template=bug_report.yml) for reproducible defects.
- [Feature requests](https://github.com/fschrhunt/code/issues/new?template=feature_request.yml) for product ideas.
- [Private vulnerability reports](https://github.com/fschrhunt/code/security/advisories/new) for security issues.

Code is maintained on a best-effort basis. Include `code version`,
your operating system, and a minimal sanitized reproduction. Never post
credentials or private infrastructure details.
