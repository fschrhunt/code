  Workframe is an interactive workspace wizard.
  Run workframe in a terminal. Start with the outcome you want, then answer only the needed prompts.

  The home screen guides you to:
    • start or continue a workspace
    • manage its reversible lifecycle
    • manage repositories, settings, and agents
    • check health or update Workframe

  Support:  workframe help  workframe version
  Scripts and coding agents:  workframe help --agent
