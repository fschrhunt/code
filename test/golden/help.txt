Workspaces — ordinary Git repositories with isolated task checkouts.

Start
  workspaces setup [--root <path>]
  workspaces clone <owner/repo | url | path>

Work
  workspaces new <repo> [task]
  workspaces list
  workspaces remove <repo/task | path> [--force]

Inspect
  workspaces root
  workspaces doctor
  workspaces version

`setup` creates or upgrades the root to README.md, repos/, and worktrees/.
Repositories live in repos/<repo>; tasks live in worktrees/<repo>/<task>.
Without a task name, `new` chooses an unused world capital. `ws` is the short
alias for `workspaces`. Workspaces only removes worktrees it created.
