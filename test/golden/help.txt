Code — Git checkouts and worktrees in one folder.

Usage
  code new <agent>
  code list
  code remove <name | path> [--force]
  code root
  code upgrade
  code version
  code help

Run `new <agent>` inside a base checkout under <root>/repos/<repo> to create
<root>/worktrees/<agent>-<repo>, suffixed -1, -2, ... when occupied. The
worktree starts detached: name a branch from the work (git switch -c <name>).
The root defaults to ~/Code; set CODE_ROOT to use another folder.
