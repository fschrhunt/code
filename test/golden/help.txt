  EXAMPLES
  wt new <repo>                Start a worktree (picks agent interactively).
  wt open                      Open a worktree in a new cursor window.
  wt archive                   Put a worktree away — keeps the branch, restorable.
  wt agents add <name>         Add an agent identity to your config.

  COMMANDS
  new        Start a new worktree to work in.
  open       Open a worktree in cursor (new IDE window).
  cd         Jump into a worktree in the terminal.
  list       List your active worktrees.
  archive    Put a worktree away — keeps the branch.
  restore    Bring an archived worktree back.
  clone      Add a repo from GitHub to the store.
  agents     List, add, or remove configured agents.
  config     Edit editor, org, and related settings.
  init       Create a local ~/.wt profile (first run).
  doctor     Check that everything's working.

  More — rename, archived, sync, clean, remove, update
