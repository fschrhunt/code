Code — ordinary Git repositories with isolated task checkouts.

Start
  code setup [--root <path>] [--yes]
  code clone <owner/repo | url | path>

Work
  code new [<repo> [task]]
  code list
  code remove <repo/task | path> [--force]

Inspect
  code root
  code doctor
  code version

`setup` is an interactive wizard in a terminal; --root answers the path and
--yes skips every prompt.
It creates or upgrades the root to README.md, repos/, and worktrees/.
Repositories live in repos/<repo>; tasks live in worktrees/<repo>/<task>.
From a base checkout in repos/, `new` can discover the repository. Without a
task name, it chooses an unused world capital.
Code only removes worktrees it created.
