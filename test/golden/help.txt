Workspaces — ordinary Git repositories with isolated task checkouts.

Start
  workspaces setup [--root <path>]
  workspaces clone <owner/repo | url | path>

Work
  workspaces new <repo> <task>
  workspaces list
  workspaces remove <repo/task | path> [--force]

Inspect
  workspaces root
  workspaces doctor
  workspaces version

Repositories live directly in ~/workspaces by default. Task worktrees live at
worktrees/<repo>/<task>. Workspaces only removes worktrees it created.
