Code — ordinary Git repositories with isolated agent worktrees.

Start
  code setup [--root <path>] [--yes]
  code clone <owner/repo | url | path>

Work
  code new <agent>
  code list
  code remove <branch | path> [--force]

Inspect
  code root
  code doctor
  code version

`setup` is an interactive wizard in a terminal; --root answers the path and
--yes skips every prompt.
It creates or upgrades the root to README.md, repos/, and worktrees/.
Repositories live in repos/<repo>; agent worktrees live flat in
worktrees/<agent>-<repo>. From a base checkout in repos/, `new` discovers the
repository and suffixes -1, -2, ... when the name is occupied.
Code only removes worktrees it created.
