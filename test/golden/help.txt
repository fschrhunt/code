  EXAMPLES

    workframe clone owner/repo                Add a repo to the store.
    workframe new repo feat --agent nova      Start a worktree for an agent.
    workframe list                            See active worktrees.
    workframe archive <sel> --yes             Put a worktree away (keeps branch).
    workframe restore <repo> <branch>         Bring an archived branch back.

  COMMANDS

    new         Start a new worktree.
    ide         Open a worktree in cursor.
    cd          Print a worktree path.
    list        List active or archived worktrees.
    archive     Put a worktree away (keeps branch).
    restore     Restore an archived branch.
    clone       Add a GitHub repo to the store.
    agents      Manage agent identities.
    config      Editor, org, profile, shared stack.
    init        Create a local or shared profile.
    status      Quick store glance.
    doctor      Deep health check.
    rename      Rename a worktree's branch.
    sync        Fetch latest for every repo.
    clean       Remove orphans (dry-run; --yes applies).
    remove      Delete a branch or repo permanently.
    update      Refresh install / sync.
