Code — Git checkouts and worktrees in one folder.

Usage
  code clone <owner/repo | url | path>
  code new <branch>
  code list
  code remove <name | path> [--force]
  code root
  code upgrade
  code version
  code help

Repositories are cloned to <root>/repos/<repo>. Run `new` inside one to create
<root>/worktrees/<branch> on branch <branch>. The root defaults to ~/Code; set
CODE_ROOT to use another folder.
