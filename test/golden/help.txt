  EXAMPLES
  wt new <repo>              Start a worktree in any repo (or just 'wt new' to pick).
  wt archive                 Put a worktree away — keeps the branch, restorable.
  wt restore                 Bring an archived worktree back.
  wt open                    Pick a worktree and open it in cursor.

  COMMANDS
  new       Start a new worktree to work in.
  open      Open a worktree in cursor.
  cd        Jump into a worktree in the terminal.
  rename    Rename a worktree's branch.
  archive   Put a worktree away — removes the folder, keeps the branch.
  restore   Recreate a worktree from an archived branch.
  list      List your active worktrees.
  archived  List archived worktrees (folder gone, branch kept).
  clone     Add a repo from GitHub to the store.
  sync      Pull the latest for every repo.
  clean     Remove safe worktrees whose remote branch is gone.
  remove    Permanently delete an archived worktree, or a repo.
  config    Set your defaults, or run guided setup.
  update    Catch this Mac up (re-mount + latest tools).
  doctor    Check that everything's working.
