  Workframe — isolated Git worktrees for parallel work.
  Use workframe or wf. Commands prompt for omitted safe details when you are at a terminal.

  Start here
    workframe init                          bootstrap a local store
    workframe setup --local                 create or update a local store
    workframe clone <owner/repo | url | path>
    workframe new <repo> <task>

  Daily work
    workframe list                         show active workspaces
    workframe open <selector>              open a workspace in the configured editor
    workframe path <selector>              print a workspace path
    workframe current                      show the current workspace context
    workframe resume <selector>            open active work or restore it
    workframe archive <selector> --yes     pause work; branch is kept
    workframe restore <repo> <branch>

  Manage
    workframe repos  workframe sync [<repo> | --all]
    workframe status  workframe doctor  workframe config
    workframe dashboard                    active work and next actions

  Migration  workframe migrate [--yes]  convert a legacy agent-scoped store after a dry run
  Workframe is Git-only: never use its lifecycle commands on a Conductor-managed workspace.
