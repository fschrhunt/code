  WORK

    new                           Start a new worktree to work in.
    ide                           Open a worktree in cursor (new IDE window).
    cd                            Jump into a worktree in the terminal.
    list                          List active worktrees (or: wt list archived).
    archive                       Put away: wt archive <sel> [--yes].
    restore                       Bring back: wt restore <repo> <branch>.
    clone                         Add a repo from GitHub to the store.

  SETTINGS

    agents                        List, add, or remove configured agents.
    config                        Editor, org, profile, and shared stack.
    init                          Create a local or shared profile.
    doctor                        Check that everything's working.

  MORE

    rename                        Rename a worktree's branch.
    sync                          Pull the latest for every repo.
    clean                         Dry-run orphans; wt clean --yes to apply.
    remove                        Delete: wt remove branch|repo …
    update                        Refresh install / sync.
