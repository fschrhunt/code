  workframe <command> [options]


  START HERE

  workframe setup                            Choose a root and agents
  workframe clone owner/repo                 Add a repository
  workframe new repo feature --agent nova    Create a workspace
  workframe ide                              Open a workspace


  WORKSPACES

  new       Create a worktree           archive   Put one away
  list      Browse worktrees            restore   Bring one back
  ide       Open in cursor              rename    Rename its branch
  cd        Print its path


  REPOSITORIES

  clone     Add a repository            sync      Fetch latest
  clean     Find orphaned worktrees     remove    Delete permanently


  SYSTEM

  agents    Manage identities           config    Preferences
  setup     Configure Workframe         status    Store overview
  doctor    Run diagnostics             update    Refresh Workframe
